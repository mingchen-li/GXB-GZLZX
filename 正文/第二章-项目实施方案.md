# 二、项目实施方案

## （一）项目概况

### 1. 项目背景、目的、意义（摘要）

本项目全称：**Agent驱动的生物医药全栈研发平台构建与创新药管线赋能**。项目立足"十五五"规划"人工智能+"行动与工信部高质量发展专项重点任务，面向我国生物医药研发工具链碎片化、领域大模型能力不足、科研智能体工程化滞后、场景落地困难等共性瓶颈，构建以领域大模型为核心、干湿闭环智能体为驱动、自动化实验室为支撑的一体化研发平台。

**项目目的：** 建成覆盖研发全流程的智能化工具链体系，研发面向小分子、核酸、多肽等对象的领域大模型，构建面向抗体设计、酶工程优化、多肽筛选等任务的科研智能体，并在新药研发、生物制品优化、生物制造工艺改进等场景形成"模型预测—实验验证—结果反馈"闭环，推动AI能力工程化、产业化落地。

**项目意义：** 提升我国生物医药自主创新能力，保障产业链供应链安全，培育新质生产力，服务制造强国与健康中国战略。

详细背景论述见《正文/第一章-项目推进计划.md》第一节"发展现状"及初版标书相关章节。

### 3. 天鹜科技主责建设内容

本项目将围绕"AI+生物医药研发全链条智能化"目标，构建一体化研发平台。天鹜科技作为牵头单位，**主责承担以下三大板块**：

1. **研发工具链与数据底座：** 多源数据统一治理与标准化调用；模块化封装集成≥10个计算/仿真工具，预置≥5个模型/算法组件；可配置科研工作流编排系统。
2. **领域大模型与核心算法库：** 针对小分子、多肽、抗体、核酸等关键对象，构建高质量领域数据集，研发具备强泛化能力的领域大模型及核心算法模块。
3. **干湿闭环智能体：** 研发能够自主调用数据、模型与计算工具的智能体，面向靶点发现、分子设计等复杂任务，实现从AI生成、实验调度到结果反馈的自主闭环。

第4板块"场景应用与创新药管线"由联合体联合单位（药捷安康、生鹜医药、舶望制药等）协同验证，天鹜科技提供平台与技术支撑。

#### 1.3 数据底座建设方案

##### 1.3.1 三类核心数据域

**（1）生物序列数据域**

涵盖DNA/RNA/蛋白质/多肽序列及其功能注释、进化信息、突变效应等。数据来源包括：天鹜科技百亿级蛋白质序列数据集（MatwingsVenus Pod）、公开数据库（UniProt、NCBI、PDB序列部分）、联合体企业授权脱敏数据【药图智能/联合药企补充】。

建设内容：
- 序列数据接入规范（FASTA/GenBank/自定义格式）；
- 序列索引与检索引擎（支持百亿级检索）；
- 功能标签体系（酶活、稳定性、表达量、耐碱性等≥【待补充】维标签）；
- 版本管理与数据血缘追溯。

**（2）分子结构数据域**

涵盖小分子三维构象、蛋白质三维结构、蛋白-配体复合物、多肽构象、核酸结构等。数据来源：PDB、ChEMBL、PubChem、AlphaFold DB、企业自有结构数据【待联合单位补充】。

建设内容：
- 结构文件标准化（PDB/SDF/MOL2/mmCIF）；
- 结构质量评估与过滤流程；
- 结合界面标注与亲和力标签关联；
- 全原子表征统一接口（对接ODesign/AnewOmni类跨模态需求）。

**（3）实验表型数据域**

涵盖酶活测定、细胞活性、表达量、理化性质、稳定性、免疫原性等实验读出值。数据来源：天鹜科技自动化实验平台（MatwingsVenus Auto）、生鹜医药/联合药企湿实验数据【待补充】。

建设内容：
- 实验数据录入模板与仪器接口；
- 实验条件元数据（温度、pH、底物浓度等）结构化存储；
- 计算预测值与实验实测值关联，支撑闭环学习；
- 数据质量分级与异常检测。

##### 1.4.2 模块化封装规范

#### 1.5 工作流编排系统

##### 1.5.1 功能需求

- **可视化编排：** 拖拽式工作流设计器，支持条件分支、并行执行、循环迭代；
- **模板库：** 预置抗体设计、酶优化、多肽筛选、小分子先导发现等典型工作流模板；
- **参数化配置：** 支持以YAML/JSON定义可复用工作流，版本化管理；
- **任务调度：** 支持本地队列、K8s、Slurm等调度后端；
- **失败重试与回滚：** 自动重试、断点续跑、中间结果缓存；
- **审计追溯：** 全流程操作日志，满足药企合规审计需求。

##### 1.5.2 典型工作流示例：酶工程优化

```
输入（目标酶序列+优化指标）
  → 序列同源搜索（BLAST/MMseqs2）
  → 突变位点推荐（MatwingsVenus-Fitness）
  → 候选序列生成（MatwingsVenus-Design）
  → 结构预测（AF2/ESMFold）
  → 稳定性/活性预测（Fitness模型）
  → Top-N候选筛选
  → 自动化表达纯化（MatwingsVenus Auto接口）
  → 酶活测定数据采集
  → 结果回流至数据底座
  → 模型微调/智能体策略更新
```

#### 1.6 解决的关键问题

1. **数据异构统一：** 通过元数据标准与统一API，解决多源数据"存得下、找得到、用得好"问题；
2. **工具孤岛打通：** 通过算子封装与工作流编排，解决"工具多但用不起来"问题；
3. **经验固化复用：** 将专家经验沉淀为可配置工作流模板，降低对个体依赖；
4. **合规可追溯：** 满足药企对研发过程审计与数据安全的要求。

#### 2.4 领域大模型研发

##### 2.4.1 MatwingsVenus蛋白大模型（核心模型一）

**定位：** 面向蛋白质/多肽/抗体/酶工程的通用领域大模型，支撑靶点识别、分子生成、性质预测、突变效应评估等任务。

**技术特点：**
- 基于百亿级序列预训练，融合结构、功能、环境多模态信息；
- 支持零样本/小样本功能预测；
- 与200+工具、30+技能深度集成；
- 支持湿实验反馈持续微调。

**核心能力模块：**
1. 序列编码器（蛋白质语言模型骨干）；
2. 结构条件生成模块（对接RFdiffusion/ODesign类能力）；
3. 突变效应预测头（Fitness Prediction）；
4. 属性多任务预测头（稳定性、表达、活性等）；
5. 检索增强模块（RAG，对接知识图谱）。

**评测指标：** 在ProteinGym等公开基准达到【待补充】水平；在联合体真实任务中验证【待补充】。

##### 2.4.2 小分子生成与性质预测模块（核心模块二）

**定位：** 面向小分子先导发现与优化的核心算法模块，可独立部署或与蛋白大模型协同。

**功能：**
- 基于靶点结构的分子生成（骨架跃迁、R-group优化）；
- ADMET多终点预测（溶解度、渗透性、代谢稳定性、毒性等）；
- 合成可及性（SA Score）评估；
- 与对接打分、MD验证工具链联动。

**技术路线：** 生成式模型（扩散/自回归）+ 物理约束 + 强化学习（实验反馈）。【详细架构设计待研发补充】

#### 3.3 三个科研智能体详细设计

##### 3.3.1 智能体一：靶点发现智能体（Agent-TD）

**任务范围：** 基于疾病关联、文献证据、组学数据、结构可药性等信息，辅助靶点识别、优先级排序、可药性评估。

**工作流程：**
1. 接收用户输入（疾病/通路/表型关键词）；
2. 检索文献、专利、知识图谱（药图智能协同）；
3. 调用组学数据分析工具【数据由联合单位提供】；
4. 结构可药性评估（PDB/AlphaFold结构+口袋分析）；
5. 输出靶点优先级列表及证据报告；
6. 人工审核节点（可配置）后进入分子设计阶段。

**人工干预减少机制：** 自动完成文献综述、数据检索、初筛打分，科学家仅需审核Top候选。

##### 3.3.2 智能体二：分子设计智能体（Agent-MD）

**任务范围：** 面向蛋白质/多肽/抗体/酶/小分子，根据靶点与设计约束，自主完成分子生成、优化、计算验证。

**工作流程：**
1. 解析设计目标（亲和力、稳定性、选择性、可合成性等）；
2. 选择设计范式（幻觉式/两阶段/共设计）与工具组合；
3. 调用MatwingsVenus大模型及工具链算子；
4. 多轮生成-评估-筛选迭代；
5. 输出Top-N候选及设计 rationale 报告；
6. 自动提交湿实验验证工单。

**典型场景：** 抗体亲和力成熟、酶稳定性改造、多肽结合剂设计、小分子先导化合物生成。

##### 3.3.3 智能体三：生物分子优化智能体（Agent-BO）

**任务范围：** 基于湿实验反馈，自主调整设计策略，完成多轮"设计-实验-学习"闭环优化。

**工作流程：**
1. 接收实验结果（活性、表达、稳定性等）；
2. 分析失败原因（结构不稳定、活性位点突变不利等）；
3. 更新优化策略（调整搜索空间、更换工具、修改约束）；
4. 生成新一轮候选；
5. 自动排程实验；
6. 循环直至满足终止条件或达到预算上限。

**闭环关键：** 与MatwingsVenus Auto自动化平台深度耦合，实验数据自动回流数据底座并触发模型微调。

#### 3.4 智能体关键技术

| 技术点 | 方案 |
| --- | --- |
| 任务规划 | 基于大模型的Plan-and-Execute，支持动态重规划 |
| 工具调用 | Function Calling + 工具链算子标准接口 |
| 结果评估 | 多指标加权评分+LLM辅助定性评估 |
| 记忆机制 | 短期（任务内上下文）+长期（项目知识库） |
| 人机协同 | 可配置审核节点、人工override、操作确认 |
| 安全护栏 | 参数边界检查、危险操作拦截、完整审计日志 |
| 可解释性 | 每步决策记录、工具选择理由、中间结果可视化 |

#### 3.5 人工干预减少≥50%的测算方法

选取联合体典型任务（如酶工程优化、抗体设计）作为基准：
- **基线：** 传统人工流程各步骤耗时与人工操作次数；
- **干预后：** 智能体自动执行步骤耗时与需人工审核次数；
- **指标：** 人工操作次数减少比例、科学家有效工时节省比例。

目标：典型场景人工干预减少≥50%，研发效率提升≥40%。【基线数据待联合体实测补充】

#### 3.6 解决的关键问题

1. **复杂任务自动化：** 将多步骤、多工具研发任务交给智能体自主执行；
2. **干湿闭环：** 打通计算与实验，实现真正的迭代优化；
3. **跨工具协同：** 智能体统一调度数据、模型、工具、实验；
4. **可审计合规：** 满足药企对AI辅助研发过程可追溯的要求。
