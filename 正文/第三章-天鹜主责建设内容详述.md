# 第三章 天鹜科技主责建设内容详述

> 本章为投标文件核心技术章节，详细阐述天鹜科技作为牵头单位主责承担的三大大建设板块：研发工具链与数据底座、领域大模型与核心算法库、干湿闭环智能体。场景应用板块由联合体联合单位主责，本章仅说明接口与协同关系。

## 第一部分 研发工具链与数据底座

### 一、建设背景与必要性

专项明确要求建成覆盖研发全流程的智能化工具链，支持不少于3类生物医药数据的统一管理与标准化调用，预置或适配不少于5个相关模型或算法组件，集成或对接不少于10个计算或仿真工具，支持多工具协同的科研工作流编排与执行。

天鹜科技已建设MatwingsVenus™平台，整合200+蛋白质设计工具、30+专家技能，具备本板块建设的坚实基础。本项目将在现有能力上进一步标准化、平台化、开放化，形成可对接联合体及行业企业的通用底座。

### 二、建设目标

| 子目标 | 具体内容 | 验收标准 |
| --- | --- | --- |
| 数据统一 | 生物序列、分子结构、实验表型三类数据统一接入与管理 | 接入清单+API测试报告 |
| 工具集成 | ≥10个计算/仿真工具模块化封装 | 工具注册表+联调日志 |
| 模型组件 | ≥5个模型/算法组件预置或适配 | 组件清单+性能基准 |
| 工作流 | 可配置、可复用科研工作流编排系统 | 模板库+3个以上端到端演示 |
| 开放接口 | 统一API供智能体与大模型调用 | 接口文档+SDK |

### 三、系统总体架构

#### 3.1 逻辑架构

平台采用分层解耦架构，自下而上分为：

**（1）基础设施层**
- 计算资源池：GPU训练/推理集群、CPU计算节点、HPC调度接口
- 存储资源池：对象存储（原始文件）、关系数据库（元数据）、向量数据库（语义检索）、时序数据库（实验仪器数据）
- 容器与编排：Docker/Kubernetes，支持工具容器化部署与弹性扩缩

**（2）数据底座层**
- 数据接入网关：支持文件上传、API推送、数据库同步、仪器直采
- 数据湖/仓：原始区、清洗区、服务区三级存储
- 元数据管理：数据目录、血缘图谱、质量评分、权限策略
- 知识增强：对接药图智能医药知识图谱【接口规范待联合对接】

**（3）工具链层**
- 工具注册中心：工具元信息、版本、依赖、资源需求
- 算子适配器：统一输入输出Schema，屏蔽底层差异
- 任务调度引擎：队列管理、优先级、并行度控制、失败重试
- 工作流引擎：DAG编排、条件分支、循环、子流程复用

**（4）服务层**
- 数据服务API
- 工具调用API
- 工作流管理API
- 监控与审计API

**（5）应用层**
- Web管理控制台
- 领域大模型调用入口
- 干湿闭环智能体调度入口
- 联合体企业定制化门户【按需部署】

#### 3.2 技术选型原则

1. **开放兼容：** 优先采用开源或可私有化部署组件，避免厂商锁定
2. **标准先行：** 数据格式、API接口、工作流定义先行标准化
3. **安全合规：** 满足医药行业数据安全与审计要求
4. **渐进集成：** 先集成天鹜已验证工具，再扩展外部工具
5. **可观测性：** 全链路日志、指标、追踪

### 四、数据底座详细方案

#### 4.1 生物序列数据域

**4.1.1 数据范围**

| 数据子类 | 格式 | 来源 | 建设优先级 |
| --- | --- | --- | --- |
| 蛋白质序列 | FASTA | MatwingsVenus Pod、UniProt | P0 |
| 核酸序列 | FASTA/GenBank | NCBI、舶望制药【待补充】 | P1 |
| 多肽序列 | FASTA | 自研项目、PubChem | P1 |
| 功能注释 | JSON/TSV | 自研标注、InterPro | P0 |
| 突变效应数据 | CSV | 实验回流、ProteinGym类公开集 | P0 |

**4.1.2 核心能力**

1. **百亿级序列索引：** 基于MMseqs2/Diamond等引擎，支持秒级同源搜索
2. **功能标签检索：** 按酶活、稳定性、表达量、pH耐受、温度范围等多维标签组合查询
3. **序列版本管理：** 同一蛋白家族/项目的序列迭代历史可追溯
4. **序列-结构关联：** 与结构数据域建立外键关联，支持"有序列查结构""有结构查同源序列"

**4.1.3 数据质量流程**

```
原始数据接入 → 格式校验 → 去冗余（CD-HIT） → 去污染（宿主序列过滤）
→ 标准化命名 → 元数据补全 → 质量评分 → 入湖/入仓 → 索引构建 → 服务发布
```

#### 4.2 分子结构数据域

**4.2.1 数据范围**

| 数据子类 | 格式 | 来源 |
| --- | --- | --- |
| 蛋白质晶体/NMR结构 | PDB/mmCIF | PDB、自研解析【如有】 |
| AlphaFold预测结构 | PDB | AlphaFold DB、自研预测 |
| 蛋白-配体复合物 | PDB/SDF | PDB、分子对接输出 |
| 小分子构象 | SDF/MOL2 | ChEMBL、PubChem、自研 |
| 多肽构象 | PDB | 自研预测/MD输出 |

**4.2.2 核心能力**

1. **结构质量评估：** Resolution、Rama-Z、Clashscore等指标自动计算与过滤
2. **结合界面提取：** 自动识别蛋白-蛋白、蛋白-配体界面残基/原子
3. **全原子统一表征：** 为跨模态大模型提供统一结构输入接口
4. **结构比对与聚类：** 支持基于TM-score的结构相似性搜索

#### 4.3 实验表型数据域

**4.3.1 数据范围**

| 表型类型 | 单位/量纲 | 来源 |
| --- | --- | --- |
| 酶活（比酶活、kcat/Km） | U/mg、M⁻¹s⁻¹ | MatwingsVenus Auto、生鹜医药【待补充】 |
| 蛋白表达量 | mg/L | 自动化平台 |
| 热稳定性（Tm、半衰期） | °C、min | DSC、加速稳定性实验 |
| 细胞活性（IC50、EC50） | nM、μM | 联合药企【待补充】 |
| 理化性质（溶解度、聚集） | 各异 | 实验测定 |
| 免疫原性评分 | 预测+实验 | 算法+实验【待补充】 |

**4.3.2 干湿闭环数据关联**

每条实验表型记录必须关联：
- 对应分子序列/结构ID
- 实验条件元数据（温度、pH、缓冲液、底物浓度等）
- 产生该候选的计算预测记录（模型版本、工具调用链）
- 智能体任务ID（如适用）

此关联机制是闭环学习与智能体优化的数据基础。

#### 4.4 元数据与数据治理

**4.4.1 元数据标准（必填字段）**

| 字段 | 说明 |
| --- | --- |
| data_id | 全局唯一标识 |
| data_type | 序列/结构/表型/文献/其他 |
| source | 来源系统或机构 |
| owner | 数据权属单位 |
| created_at / updated_at | 时间戳 |
| version | 数据版本号 |
| quality_score | 质量评分0-100 |
| access_level | 公开/内部/机密 |
| lineage_parent | 上游数据ID列表 |
| experiment_conditions | 实验条件JSON（表型数据必填） |

**4.4.2 数据血缘示例**

```
公开PDB结构 → 界面提取 → 逆折叠设计序列 → 结构再预测 → 稳定性预测
→ Top5候选 → 自动化表达 → 纯化 → 酶活测定 → 测定结果回流
→ 模型微调 → 下一轮设计
```

每一步均在血缘图谱中记录，支持审计与复现。

**4.4.3 权限与安全**

- 按联合体协议划分数据可见范围
- 企业机密数据物理/逻辑隔离
- 操作审计日志保留≥【待补充】年
- 敏感数据脱敏后方可用于共有模型训练

```yaml

  name: "AlphaFold2结构预测"
  version: "2.3.2"
  category: "structure_prediction"
  inputs:
    - name: sequences
      type: fasta
      required: true
    - name: msa_mode
      type: enum
      values: [single, uniref, custom]
      default: uniref
  outputs:
    - name: structures
      type: pdb
    - name: confidence
      type: json
  resources:
    gpu: 1
    memory_gb: 32
    timeout_minutes: 120
  container: "registry.matwings.ai/af2:2.3.2"
```

## 第二部分 领域大模型与核心算法库

### 一、建设背景

专项要求构建不少于2类典型研发对象（如小分子、核酸、多肽）的领域数据集，研发不少于2个领域大模型或核心能力模块，推动其在靶点识别、分子生成、性质预测等任务中的泛化应用。

天鹜科技已建成十亿参数量级蛋白质预训练模型，入选国家数据局高质量数据集典型案例。本项目将在此基础上升级跨模态能力，并补齐小分子等模块，形成≥2个大模型/核心模块的指标组合。

### 二、技术路线

#### 2.1 总体路线

```
高质量多模态数据 → 统一表征学习 → 任务专用头/模块 → 工具链集成部署
        ↑                                                    ↓
        └──────────── 湿实验反馈持续学习 ←──────────────────┘
```

#### 2.2 分子设计范式融合

本平台大模型研发吸收国际三类范式成果：

1. **幻觉式：** 用于快速序列空间搜索与初筛
2. **两阶段式：** 用于工程稳定性要求高的蛋白/多肽设计
3. **共设计式：** 作为中长期攻关方向，向全原子跨模态统一生成演进

上海交大协同攻关共设计式/跨模态模块；天鹜负责工程化、集成与产业验证。

### 四、大模型与核心模块研发

#### 4.1 核心模型一：MatwingsVenus蛋白领域大模型

**4.1.1 模型定位**

面向蛋白质、多肽、抗体、酶工程的通用领域大模型，是平台AI能力的"认知内核"，支撑靶点可药性评估、序列设计、突变效应预测、属性多任务预测等。

**4.1.2 模型架构（规划）**

| 模块 | 技术方案 | 说明 |
| --- | --- | --- |
| 骨干网络 | Transformer蛋白语言模型 | 基于百亿级序列预训练 |
| 结构条件注入 | 结构编码器+交叉注意力 | 支持结构引导设计 |
| 多任务头 | 共享编码器+任务专用头 | 功能、稳定性、表达等 |
| 检索增强 | RAG+向量检索 | 对接知识图谱与序列库 |
| 对齐模块 | 指令微调+RLHF/实验反馈 | 对齐科学家偏好 |

**4.1.3 训练策略**

| 阶段 | 数据 | 目标 |
| --- | --- | --- |
| 预训练 | MVS-Seq-Core | 序列表示学习 |
| 多任务微调 | 功能/稳定性标注 | 下游任务能力 |
| 结构条件训练 | MVS-Struct-Bind | 结合剂设计 |
| 实验反馈学习 | 湿实验回流数据 | 闭环优化 |
| 指令对齐 | 专家标注+文献 | 智能体友好输出 |

**4.1.4 评测体系**

| 基准 | 指标 | 目标 |
| --- | --- | --- |
| ProteinGym | 突变效应相关性 | 【待补充，力争领先】 |
| 联合体真实任务 | 实验成功率、活性提升 | 管线级验证 |
| 计算效率 | 推理延迟、吞吐量 | 满足生产环境 |

#### 4.2 核心模块二：小分子生成与性质预测模块

**4.2.1 模块定位**

面向小分子先导发现与优化，可独立运行或与蛋白大模型协同（如蛋白-配体共设计场景）。

**4.2.2 功能清单**

1. **靶点结构准备：** 从PDB/AlphaFold获取靶点结构，口袋识别
2. **分子生成：** 基于骨架跃迁、片段生长、R-group优化等策略
3. **虚拟筛选：** 对接打分+药效团匹配+多样性筛选
4. **ADMET预测：** 溶解度、渗透性、代谢稳定性、hERG、肝毒性等
5. **合成可及性：** SA Score、逆合成分析【工具集成】
6. **优先级排序：** 多目标加权，输出Top-N候选

**4.2.3 技术方案**

- 生成骨干：扩散模型或自回归SMILES/图生成
- 物理约束：对接打分、药效团、合成可及性作为奖励
- 强化学习：以实验/专家反馈优化生成策略
- 与工具链联动：自动调用Vina、ADMET、MD验证

#### 4.3 扩展模块（支撑指标与协同）

| 模块 | 功能 | 负责 |
| --- | --- | --- |
| 核酸序列优化模块 | siRNA/ASO序列设计辅助 | 天鹜接口+舶望数据【待补充】 |
| 抗体人源化模块 | CDR移植、免疫原性降低 | 天鹜 |
| 酶催化口袋模块 | 活性位点识别、底物适配 | 天鹜 |

### 五、模型部署与服务

#### 5.1 部署架构

- **训练集群：** 分布式预训练与微调
- **推理服务：** Triton/vLLM等推理框架，支持批量与在线
- **模型注册中心：** 版本、A/B测试、灰度发布
- **API网关：** 鉴权、限流、计费【如对外服务】

#### 5.2 与工具链集成

大模型不作为孤立系统，所有预测/生成能力均通过工具链算子封装，供工作流与智能体统一调用。

## 第三部分 干湿闭环智能体

### 一、建设背景

专项要求研发不少于3个面向靶点发现、分子设计或生物分子优化等任务的科研智能体，支持跨数据、模型与工具的自主调用，实现多步骤科研任务自动化执行，在典型场景中人工干预减少50%以上。

天鹜科技已开发MatwingsVenus Agent，并在上海市科学智能"百团百项"项目中攻关"AI生物学家"智能体。本项目将升级为面向生物医药全栈研发的多智能体体系。

### 二、智能体体系架构

#### 2.1 多智能体协作框架

```
                    ┌─────────────────┐
                    │  编排智能体（Orchestrator）  │
                    │  任务分发 / 进度统筹        │
                    └────────┬────────┘
           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
    │ Agent-TD    │  │ Agent-MD    │  │ Agent-BO    │
    │ 靶点发现     │  │ 分子设计     │  │ 生物分子优化  │
    └─────────────┘  └─────────────┘  └─────────────┘
           │                 │                 │
           └─────────────────┼─────────────────┘
                             ▼
              ┌──────────────────────────┐
              │  共享能力层                │
              │  记忆 / 知识 / 工具 / 模型  │
              └──────────────────────────┘
```

#### 2.2 核心设计原则

1. **领域增强：** 生物医药领域知识库+大模型推理，非通用LLM裸用
2. **工具接地：** 所有结论尽可能基于工具调用结果，减少幻觉
3. **人机协同：** 关键节点可配置人工审核，非完全黑盒
4. **全程可审计：** 每步决策、工具调用、参数、结果可追溯
5. **闭环进化：** 实验反馈驱动策略与模型更新

### 三、智能体一：靶点发现智能体（Agent-TD）

#### 3.1 能力边界

- **输入：** 疾病名称、通路、生物标志物、表型描述、竞品药物等
- **输出：** 靶点优先级排序列表、证据报告、可药性评估、建议下一步实验

#### 3.2 执行流程（典型12步）

| 步序 | 动作 | 调用能力 | 人工介入 |
| --- | --- | --- | --- |
| 1 | 意图澄清 | LLM对话 | 可选 |
| 2 | 文献检索 | 知识图谱+PubMed API | 无 |
| 3 | 专利检索 | 专利数据库【待接入】 | 无 |
| 4 | 疾病-靶点关联 | 知识图谱推理 | 无 |
| 5 | 组学证据 | 联合单位数据【待接入】 | 无 |
| 6 | 靶点可药性 | 结构口袋分析 | 无 |
| 7 | 竞争格局 | 文献+数据库 | 无 |
| 8 | 安全性预警 | 脱靶、表达谱 | 无 |
| 9 | 综合评分 | 多维度加权 | 无 |
| 10 | 报告生成 | LLM总结 | 无 |
| 11 | 专家审核 | 人工确认 | **是** |
| 12 | 流转设计 | 触发Agent-MD | 可选 |

**人工干预减少：** 步骤1—10自动完成，科学家仅需审核（步骤11），相比传统全流程人工检索分析，操作步骤减少约60%【待基线实测确认】。

### 四、智能体二：分子设计智能体（Agent-MD）

#### 4.1 能力边界

- **输入：** 靶点信息、设计约束（亲和力、选择性、稳定性、可合成性等）、分子类型
- **输出：** Top-N候选分子、设计理由、预测性质、实验建议

#### 4.2 分子类型覆盖

| 分子类型 | 设计范式 | 主要工具/模型 |
| --- | --- | --- |
| 蛋白质/酶 | 定向进化/从头设计 | MatwingsVenus-Design, RFdiffusion |
| 多肽 | 结合剂设计/稳定性优化 | Design+AF2 |
| 抗体 | CDR优化/亲和力成熟 | Design+人源化模块 |
| 小分子 | 生成+优化 | SmallMol-Gen+Docking |

#### 4.3 推理-行动循环（ReAct）

```
Thought: 分析设计目标与约束
Action: 调用工具/模型
Observation: 获取结果
Thought: 评估是否满足条件
Action: 调整策略或继续
... 循环直至满足终止条件
Final Answer: 输出候选与报告
```

#### 4.4 自主决策示例

面对"提升酶热稳定性10°C"任务，Agent-MD自主：
1. 查询同源序列分析保守位点
2. 预测野生型结构识别不稳定区域
3. 生成突变候选
4. 批量结构预测与稳定性评估
5. 筛选Top10
6. 自动提交湿实验工单

全程无需科学家逐步指定工具与参数。

### 五、智能体三：生物分子优化智能体（Agent-BO）

#### 5.1 能力边界

- **输入：** 上一轮候选及实验结果（活性、表达、稳定性等）
- **输出：** 下一轮优化候选、策略调整说明、终止建议

#### 5.2 闭环优化策略

| 实验结果模式 | 智能体策略调整 |
| --- | --- |
| 活性低但表达好 | 聚焦活性位点突变，缩小搜索空间 |
| 活性好但不稳定 | 引入稳定性导向突变，结构区域优化 |
| 表达差 | 密码子优化、可溶性标签建议、表达条件推荐 |
| 多目标冲突 | 帕累托前沿搜索，提供权衡方案 |

#### 5.3 与自动化实验平台耦合

| 接口 | 功能 |
| --- | --- |
| 工单创建 | 智能体自动生成实验工单（序列、表达条件、检测方法） |
| 进度查询 | 实时获取实验状态 |
| 结果回调 | 实验完成自动推送结果至智能体 |
| 异常处理 | 实验失败时自主决定重试/调整/上报 |

MatwingsVenus Auto平台提供上述接口能力。

#### 5.4 迭代终止条件

- 达到预设指标阈值（如活性提升≥X倍）
- 达到预算上限（实验轮次/成本）
- 收益递减（连续N轮无显著改善）
- 人工指令终止
